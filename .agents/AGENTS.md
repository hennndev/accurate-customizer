# Project Rules & Guidelines - Accurate Customizer

## Handoff Documentation Requirement
- **Rule:** Every time a modification, bugfix, refactoring, or feature addition is made in this codebase, the agent MUST update `HANDOFF.md` in the project root to reflect the current state, changes made, and any new workflow notes.
- **Goal:** Ensure `HANDOFF.md` remains the single source of truth for project handovers, tracking end-to-end (hulu ke hilir) functionality accurately across sessions.
